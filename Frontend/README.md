# BuildPro

Construction management workspace. This build is the frontend only: screens read and update data in the browser. Login accounts live in `src/data/users.json`.

## Run

```bash
cd Frontend
npm install
npm run dev
```

Open the URL Vite prints, usually http://localhost:5173.
